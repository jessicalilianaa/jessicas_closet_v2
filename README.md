# Jessica’s Closet — versão 2 (PT-BR)

Esta pasta contém um protótipo de jogo de vestir com interface adaptada para celular.

## Arquivos
- `index.html`: jogo interativo, sem bibliotecas externas.
- `referencia-visual.png`: imagem de referência estética para orientar futuras melhorias.

## Como publicar pelo iPhone usando GitHub Pages
1. Descompacte o ZIP no app Arquivos.
2. Entre no repositório no GitHub pelo Safari.
3. Faça upload do `index.html` na raiz do repositório (não dentro de uma subpasta).
4. Em Settings → Pages, escolha Deploy from a branch, `main` e `/ (root)`, depois Save.
5. Aguarde e abra o endereço exibido em Settings → Pages.

## Limitações honestas
Esta é uma demonstração HTML/CSS/JavaScript. A personagem é desenhada em CSS e as peças são representadas por escolhas visuais/cores e emojis; ainda não é um avatar 3D realista. Os favoritos e looks salvos são uma simulação local e não persistem após recarregar a página. O arquivo de referência visual é apenas inspiração, não uma tela funcional.
